% FONT NOTE
%
% Tectonic runs XeTeX and this machine's fontconfig is broken ("Fontconfig
% error: Cannot load default config file"), so fontspec cannot resolve system
% font names such as "TeX Gyre Termes" -- it hard-errors. newtxtext/newtxmath
% ship Times and the math faces as Type1 fonts inside the TeX tree instead, so
% they need no fontconfig.
%
% These MUST be loaded after \documentclass. Loading them before fails: LaTeX
% rejects \usepackage before \documentclass, and \RequirePackage before it fails
% harder, because newtx pulls in xkeyval, which cannot load that early either.
%
% The cost of that ordering is ~47 "Font shape `TU/ptm/.../n' undefined"
% warnings: IEEEtran selects the `ptm` family internally before newtx claims the
% shapes. The warnings are benign. Verified in the output PDF -- the embedded
% fonts are TeXGyreTermesX (text), TeXGyreTermesX-Italic (italic) and NewTXMI
% (math), which is the Times IEEE specifies, not the Latin Modern fallback the
% warnings describe.

% IEEEtran IS the IEEE template: it supplies the two-column conference body,
% \IEEEauthorblockN / \IEEEauthorblockA author metadata, \IEEEkeywords, and
% IEEEtran.bst for the numeric reference list. No ARS-shipped LaTeX reference
% covers IEEE (academic-paper/references/latex_template_reference.md ships
% `article` and `apa7` only), so IEEEtran is the authority here.
